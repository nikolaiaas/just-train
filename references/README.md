# Design references

These HTML concept boards and rendered images are visual inputs for the Bare
Træn applications. They are not shipped as application source.

- `bare-traen-skaermforslag.html` and its PNG preview cover the child-facing
  mobile flow.
- `bare-traen-administration.html` and its PNG preview cover the content
  administration flow.
- `bare-traen-avatar.jpg` is the synthetic reference avatar used by the boards.

Keep personal photos and videos out of this directory. Development fixtures
must remain synthetic or use consenting adults until the consent and retention
rules are approved.
